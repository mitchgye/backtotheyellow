Studio setup

LOCAL NETWORK
Enable Game Settings → Security → Allow HTTP Requests in Roblox Studio. Roblox must be able to reach this server; localhost is only accessible on the same machine. For a published game, expose the server securely over a reachable HTTPS endpoint.
Optional write authentication: configure API_KEY in your server environment and send X-API-Key for protected changes. Never put a secret in a published client-side script. This single-file UI expects an API server at its current origin.

Example HttpService request

ROBLOX LUA
local HttpService = game:GetService("HttpService")
local response = HttpService:GetAsync("http://YOUR_HOST:3000/api/director/next")
local result = HttpService:JSONDecode(response)
if result.success and result.memory then
		print("Memory selected:", result.memory.name)
end
